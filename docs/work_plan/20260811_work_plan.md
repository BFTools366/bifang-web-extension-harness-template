### 目标与路径

- 路径：里程碑。

- 范围内：公开脚本与 CLI 分发、底层初始化路径门禁、源内目标拒绝、Harness 自校验、零写入回归、长期文档与项目 Skills、Web/Extension 两种独立下游的真实生成验收。

- 门禁语义：底层初始化器以当前执行的 `.harness/tooling/init.ts` 所属规范化 Harness 根为边界，拒绝相同根及其全部子路径；`instantiate` 仍只允许目标位于源外，并在目标同级 staging 中调用内部初始化步骤。
