# 2026-10-19 产品状态

## 当前能力

Harness 维护 React Web 与 Plasmo Chrome MV3 / Firefox MV2 Extension 两种互斥单包。带需求文档和无文档均进入明确首版范围、工程事务、下游 PRD、单个原型、实际接线与开发验证；初始化成功不替代首版完成。

七项独立能力按操作最小依赖接线。身份、组织、权限、购买恢复、公开设置、Query 与作用域各有明确所有者，未选功能不产生业务入口。固定资产允许内容和 fixture 定制，Mock 与真实 adapter 的验证边界明确。

当前设计由 [今日 ADR](../adr/20261019_ADR.md) 及其链接的唯一事实源维护；旧 ADR 与变更描述原样归档，历史不作为现行规范。无活动工作计划，不创建占位计划或验收记录。
