# 产品状态索引

本目录只在重要阻断、跨会话交接、真实发布完成或用户明确要求时保存 Web Harness 当前阶段、已完成事项与下一步。候选构建、E2E 和中间验收不逐次写状态快照。

## 写入规则

- 文件名固定为 `YYYYMMDD_product_status.md`；同一天只维护一份产品状态。
- 新自然日首次写入时读取前一份状态，把仍有效事实与当日变化重写为完整当前快照，不复制流水账。
- 普通缺陷修复、行为保持重构、格式整理、测试补强和内部清理本身不触发状态文件。
- 只保留日期最新的状态文件；被完整取代的旧日期文件删除，历史由 Git 保存。
- 最终候选形成但尚未完成发布时，不把“构建成功”误写为真实发布完成。
