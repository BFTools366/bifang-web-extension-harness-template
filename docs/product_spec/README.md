# 产品规格索引

本目录是 Web Harness 产品目标、范围、约束与可衡量成功标准的唯一当前正文来源。

## 写入规则

- 文件名固定为 `YYYYMMDD_product_spec.md`，日期使用需求确认所在时区的自然日。
- 同一天只维护一份产品规格；只有产品目标、公开边界、约束或成功标准真实变化时才更新。普通缺陷修复、行为保持重构、格式整理、测试补强和内部清理不触发规格写入。
- 新自然日首次写入时先读取前一份产品规格，把仍有效内容与当日决定整理为完整快照，不写增量流水账。
- 只保留日期最新的规格文件；被完整取代的旧日期文件删除，历史由 Git 保存。
- 新下游在目标仍未确认时使用 `Draft` 与明确待定项，不继承源 Harness 的批准事实。
