# 2026-10-23 变更记录

本文件只呈现当前有效变化；当前设计见 [ADR](../adr/20261023_ADR.md)，更早记录通过 Git 历史追溯。

## Added

- 自建 Server 首次发布时，空 BaseURL 从生产配置推导本机回环地址并提示确认；确认后补齐选中前端配置，已有地址保持不变。
- 旧 Go 服务发布迁移支持外部只读提案、缺失工具补齐与函数级配置合并，保留业务代码、已有生产配置及自定义校验。

- Workspace 根发布入口统一生成 release/web.zip、extension.zip 与 server.zip；Web 保留项目名_web 顶层，扩展包含 Chrome/Firefox 两目标，Server 询问目标平台并携带单份生产配置。
- Go 配置文件拥有数据库与运行参数；生产导出不混入开发覆盖或本机环境秘密，缺失配置失败，代码只提供安全退级。

- 可复用八表账号/团队 RBAC 与邀请生命周期：开户原子建立自有团队，双向加入保持各自数据；共享和成员私有数据拥有明确模型及事务授权入口。详见 [数据归属基线](../ACCOUNT_OWNERSHIP.md)。
- 完整 identity.workspace 和 Go 账号装配 helper 接通真实团队上下文、邀请、成员角色分配、角色维护及有效权限读取；原始上游快照保持不变。

- Workspace 原地工程升级：根统一所有权与上游基线，分别投影根协作工具和前端成员，保护 Go 服务、运行配置、品牌、产品和已有修改；提供源外纯工程候选及只读旧目标引导提案。详见 [升级合同](../../.agents/skills/web-upgrade-harness/references/workspace-upgrade.md)。

- Workspace 根包装所选 Web、Extension 与 Go Server，目录采用 _web/_extension/_server 后缀；一个 Git、依赖锁与共享产品事实。
- 新增 17 个 Workspace/Go Skills，按领域实施两端与真实接口；固定 Go 来源资产、持久化、用户 owner 成员、GraphQL 引导与各专用能力独立协作。

- 创建支持可选需求文档：冻结 UTF-8 原文和摘要，在同一 staging/基线交接到下游；无文档时逐项澄清首版需求，不要求重贴已有输入。
- 身份、组织、权限、商品、订单、钱包支付和审计拥有独立知识、固定设计及两宿主接线资产。操作图计算最小依赖及原因，未选能力不生成入口或请求；真实首页由需求实施。
- 新增公开设置页，统一承载语言与外观，匿名和登录用户均可使用；认证页底部入口安全返回，不把凭据放入查询参数，也不隐式生成账号资料功能。
- 主壳保持正文、侧栏上下文和账号组合槽位；账号菜单按实际选择接入组织，组织页、菜单及侧栏共用私有 Query，切换期间外壳持续存在。
- API 契约、模块边界、访问控制、写入恢复、存储、事件、Task、HTTP 接入、Extension 兼容、Worktree 审计与升级预演均可按事件独立调用；[Skill 地图](../harness_engineering/skill_composition.md) 维护当前职责。
- API 导出按业务聚合接口与已实现流程，统一结构、元数据和双向关联；保留真实不符合项，不输出本地代码或路径。
- 项目内缺失的设计支持从固定快照补装，已有有效版本保留；身份支持明确中英翻译，Logo 母版派生当前宿主资源。

## Changed

- 接口协议收敛为仅列表查询和其他带业务查询条件的 GET 类读取强制 GraphQL，其余请求全部 RESTful；同步两宿主派生规则、Skills 和 API 导出双向校验。组织上下文、成员权限快照迁到 REST，账号装配不再暴露来源 health/me GraphQL 根字段；旧来源示例如实保留为协议不符合项。

- Harness 升级支持旧 Workspace 根 runtime 规则的只读迁移提案和获批追加，继续拒绝冲突与额外授权；提案明确列出发布脚本、忽略规则和既有 Go 配置的手工审查范围。
- 发布压缩支持取消并保留旧 ZIP；升级 helper 按依赖顺序更新，避免新消费者先于导出提供者造成 CLI 启动失败。
- Workspace 创建裁剪源专属文档并适配根共用规范链接；旧工程升级保留精确清理审查，源文档残留仍阻断规划。

- 创建 SOP 从需求采集开始，充分需求唯一适配的宿主、必要能力及本地方案优先自动选择；等价方案或争议才推荐。推导独立记录来源和理由、随需求修订失效，现成服务等外部事实按需补齐；品牌取消无条件三选一，完整汇总仍一次确认。

- 多场景走查修正：显式纯本地模式不生成服务端；完整账号可按明确范围收敛协作入口；服务来源与策略阶段修订保留有效答案并清除失效依赖，需求追加保留全文。

- 账号菜单收敛为邮箱/昵称、可点击组织名称、个人设置和退出登录；组织设置与加入组织移到左侧组织管理分组。完整账号默认生成个人设置，接通本人昵称保存和改密，改密成功清会话并返回登录。
- 创建时 Agent 设置默认采用预设，不再询问策略模式；主动自定义仍复用明确值并补齐缺项，最终汇总展示实际配置。
- 自建邮箱注册默认要求验证码。尚无邮件服务时仅开发环境模拟投递，发送后在表单显示实际验证码；接通 SMTP 并关闭模拟后自动移除回显，账号与验证码校验仍由真实后端完成。
- 需求分析固定账号拥有自有组织、加入他人组织并通过切换查看数据；同一业务保持一个入口。界面统一称“组织”，标题、标签、占位和反馈使用自然语言，删除实现术语与重复说明。

- identity 模块默认选择完整用户基线；底层 identity.session 仍可按操作独立选择，但不作为完整用户系统交付。已有服务需提供等效可信合同，存量产品不自动重装或迁移。

- 初始化先收集需求；Agent 澄清后给出服务端建议及理由，再询问尚未明确的服务来源和开发 BaseURL，已有明确选择直接复用；没有服务同事务创建 Go 并连接前端，不另开 Go 功能问卷。可选可信契约文件内容进入确认修订与根文档。
- 新产品禁止运行时业务 Mock；基础装配仅接受真实 adapter，测试替身移至测试目录。扩展操作未实际接线时明确交领域 Skill 实施。
- 既有单包保持原地维护；Workspace 从根升级且成员不能独立记录基线，整体目录或布局迁移仍需单独合同。

- 完整创建一次确认后连续完成工程事务、下游唯一 PRD、单个桌面交互原型、自查登记、首版实施和开发走查。工程成功只报告 `ENGINEERING_READY`，失败保留并修复现场，不以脚手架代替首版。
- 创建、需求、能力、设计与实施各有唯一职责；阶段交接复用已有批准，单向委托、按需读取，不增加重复问卷或事实来源。
- 基础身份接齐登录、用户区、守卫、安全返回、Token、退出/401；权限同时约束路由、导航、页面、元素及提交前复核。购买最小依赖包含身份、目录、订单和钱包，未决购买跨弹窗与路由保留幂等关联，不自动重放。
- 组织尚未选择时允许选择唯一候选；切换未知结果先重读权威上下文，再刷新权限恢复。明确未切换保留已确认会话并报错，无法确认或已被新作用域替代时安全处理。
- 只读订单省去未选创建/恢复/结算实现；隔离测试 fixture 按主体区分并支持取消。能力页复用 HTTP 错误分类，401/403 无普通重试，服务响应查询按语言隔离。
- 提取既有主壳、认证与交易交互时记录来源层级和摘要；项目身份、模板文案、已选页面及 fixtures 可定制，产品接口使用真实 typed adapter，内存替身仅留隔离测试，离线参考不冒充真实交易实现。
- API/存储统一归 `src/data/`；Ky 复用请求边界、认证 revision、401 与 ApiError；Query 唯一管理有限服务缓存，Jotai 和 React 仅管理各自客户端状态。远端列表统一 GraphQL，其他协议和依赖随真实消费者引入。
- Web 使用文件路由及临时路由树，列表 search 唯一拥有已应用状态，仅无 owned key 时恢复一次 session 快照。Extension Popup/Options 使用独立 memory/hash Router，Chrome MV3 与 Firefox MV2 分别构建和验证，不继承 Web 列表或跨入口会话。
- Mantine theme 集中系统字体、品牌十阶色、语义令牌和默认 auto；语言同步文档，控件具备标签、键盘和焦点语义，不预装未选 UI 包。
- Node/pnpm/独立 CLI 全局管理，项目依赖由本地 manifest/lock 管理；最低 Node 24.0.0、pnpm 12.8.1，TypeScript 保持 6.0.3，pnpm allowBuilds 不建立 workspace。实际依赖运行要求见 [README](../../README.md)。
- 工程按功能内聚、单向无环依赖、中文声明注释与代码 500/600 行约束治理；升级双基线保护产品与本地修改，新增 helper 先收敛，源门禁独立锚定所有权下限。
- 左侧 Task 使用三字段标题与真实 Git/项目绑定，内部只读子代理和写入并行分别受各自触发条件约束；日常实现不自动追加计划或完整候选。
- 发布复用当次 E2E 选择，smoke 独立解析；唯一 Release 构建/打包自动检查环境、格式、lint、类型、全测、版本与泄漏。明确发布请求覆盖既有目的地的必要提交和推送，新增范围才补授权。
- 按用户指定的 2026-10-20 截止日期清理更早的 ADR 条目、ADR/Changelog 历史卷与状态记录；同步当前规格、状态和索引，保留仍有效的工程合同及 10 月 20 日起的决定，更早记录通过 Git 历史追溯。

## Removed

- 退役 Web 产品分类、创建购买开关及三个模式 Skill，旧路径仅作为升级 tombstone；不恢复分类驱动功能启用。
- 删除默认欢迎页、计数器、演示全局状态、伪 Query 和多方案原型要求，保留真正的工程基础与首版需求边界。

## Security

- 前端菜单、路由及提交前只判断有效权限 code；后端通过真实 RBAC 及资源归属校验，无 owner 名称旁路。角色授予不能超过操作者权限，复合外键拒绝跨团队角色/成员绑定。

- 凭据、组织、权限与迟到响应按主体/作用域隔离，结构化主体键避免幂等关联碰撞；Mock 不授予真实服务或资金授权。
- Extension 身份消息安全编码美元，双目标 build/package 固定 production 输入输出并分别扫描 manifest、资源、版本与 bundle，拒绝运行时裸依赖 self-map。

## Scope

- 当前以 Workspace 为根，所选 React Web 或 Plasmo Chrome MV3 / Firefox MV2 Extension 前端成员各自单包且唯一宿主，并按明确服务来源接入已有服务、创建 Go 成员或仅在本地实现；真实服务、生产账号、扣款、商店、桌面和其他平台不因生成或测试替身通过而视为已验证。

## Security

- 自建用户模块拒绝生产公开默认 JWT 密钥；生成的访问日志默认不记录正文，显式记录响应时对凭据脱敏。
