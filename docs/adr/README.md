# ADR 索引

本目录是 Web Harness 产品边界、长期重要且难以逆转的工程决定与硬规则例外的唯一当前正文来源。

## 写入规则

- 文件名固定为 `YYYYMMDD_ADR.md`；同一天只维护一份，并在顶部加入新的独立 `ADR-YYYYMMDD-NNN`。
- 普通需求、缺陷修复、行为保持重构、格式整理、测试补强、内部清理和实现细节不创建 ADR。
- 每条至少记录状态、背景、决定、影响、理由、风险、验证与恢复/调整条件。
- 只保留日期最新的 ADR 文件；旧日期被完整取代后删除，历史由 Git 保存。
- 当前文件超过 500 行或负责人明确要求时，源 Harness 可用 `$web-curate-harness-memory` 把已被完整取代且无当前引用的原文追加到 `ADR_history.md`；该 Skill 与历史卷不派生到下游。
