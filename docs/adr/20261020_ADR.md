# 2026-10-20 架构决策记录

## ADR-20261020-002：Workspace 与按领域协作的真实 Go 服务

- 状态：Accepted。依据：用户本次明确要求学习 Go Harness、组合创建 Workspace、按已有服务与自建服务接线、拆分协作 Skills 并取消前端业务 Mock。
- 背景：原入口把独立单包、宿主互斥、空地址 Mock 与前端限定写入生成事务、规则、表单及能力资源，不能只把目录改名或复制后端问卷。
- 决定：新下游根拥有唯一 package.json 包装器、Git、pnpm 锁、策略、PRD 与 API 文档；按实际选择创建 <id>_web、<id>_extension、<id>_server，成员内部保持单宿主和单向模块边界。已有服务必填开发 BaseURL，可信接口按操作核对；没有服务同时创建并连接 Go 成员，不另开 Go 初始化问卷。
- 能力：领域 Skill 协调用户、组织、权限、商品、订单、钱包与审计；Go 叶子拥有服务、持久化、GraphQL、真实验证码、文件、子进程、本地构建与测试。产品只接真实 typed API，测试替身留在隔离测试。未实现操作必须由领域 Skill 增量实现，能力清单不能冒充已完成代码。
- 来源与适配：Go 资产固定提交与逐文件 SHA-256，保留原许可；旧问卷、Mock、发布状态不迁入。账号注册补齐自有组织及 owner 成员的同事务创建，profile 权威验证完整关系。gqlgen 引导输出是精确路径、固定字节的真实生成物，人工文本行数豁免只适用该文件，后续按 SDL 重新生成。
- 替代范围：取代前序决定中的“新下游必须平铺互斥单前端”和“未配置业务 API 运行 Mock”路线；既有独立前端仍原地维护。原单包升级器不支持 Workspace 根或成员，另行迁移须有逐路径合同。
- 理由与影响：需求、接口、前后端实现和联调成为同一结果；生成仍只承诺工程事务，完整创建必须继续完成用户选定首版。
- 风险与验证：现有服务不能从 BaseURL 猜接口；发送通道、支付、部署与生产数据副作用仍按真实合同和授权。需验证组合生成、事务回滚、共享锁/策略、原型根归属、HTTP 协议桥、真实注册与持久化、错误及退出失效。具体执行结果留当次回复，不写入本条作为固定事实。
- 调整与恢复：现有下游不自动迁移，源变更可按审查差异回退；产品身份、持久数据与服务归属变化另立迁移合同。详细事实归 [Workspace](../WORKSPACE_TEMPLATE.md) 与 [Go 服务](../GO_SERVICE.md)。

## ADR-20261020-001：完整账号与组织基线及账号菜单归位

- 状态：Accepted，仅表示通用设计与接线规范获准，不表示运行时代码或发布候选已验收。
- 依据：本会话用户审阅账号与组织交互原型后，明确回复“确认，按这版更新知识库与接线规范”。本次授权覆盖知识库、固定设计和接线规范，不覆盖运行时代码改造。
- 背景：知识层把注册自有组织限定为另选生命周期，账号资料只有槽位，旧侧栏展示组织区；相关 Mock 使用成员 actor 分区，不能代表组织共享数据的租户边界。
- 决定：完整用户信息包含 Account、当前 Organization 和有效 OrganizationUser；每个注册账号原子获得一个自有组织及 owner 成员，加入他人组织只新增成员。organizationId 是组织数据的租户边界，OrganizationUser.id 是成员授权主体、成员私有范围及审计操作者。详细不变量归[身份知识](../../.agents/skills/web-compose-capabilities/knowledge/identity.md#完整用户信息)及[组织知识](../../.agents/skills/web-compose-capabilities/knowledge/organization.md)。
- 布局：Web 工作区默认侧栏仅工作台与底部设置；账号信息、当前组织、切换、拥有者组织管理、加入与退出集中在右上账号菜单。单组织仍保留工作区侧栏与加入入口；Extension 按宿主采用紧凑导航。详细结构归[UI 规范](../MANTINE_UI_GUIDELINES.md#81-功能组合的页面与布局)和[固定设计](../../.agents/skills/web-compose-capabilities/templates/application/design.md)。
- 替代范围：本条修订 ADR-20261019-003 中完整用户方案可仅依赖基础身份及按来源布局推导的目标要求。低层认证 helper 和当前 catalog 的独立性继续保留，但不能代替完整用户信息或缩减已确认需求；其余前序决定继续有效。
- 影响与理由：统一注册、邀请、切换与数据边界，避免账号加入别人组织后丢失自有组织，避免把成员 actor 当全部组织数据键，并使低频账号操作离开默认侧栏。
- 风险与边界：不改当前 catalog、应用装配器、fixture 形状或运行时，也不迁移既有账号与业务数据；不编造邀请 endpoint、权限码、签发、自动登录或凭据持久化授权。原型的注册后直接进入仅为演示，真实服务合同优先。
- 验证要求：知识与布局引用保持一致；后续实现覆盖注册原子性、邀请前后成员资格、自有组织保留、同组织授权共享/跨组织拒绝、owner/member 入口、干净侧栏及切换未知结果恢复。当前实现差异由[接线合同](../../.agents/skills/web-compose-capabilities/templates/application/wiring.md#当前装配器与目标规范的差异)列明，在[技术债](../TECH_DEBT.md)跟踪，不以文档批准冒充已实现。
- 负责人及调整条件：执行 Agent 维护规范，用户决定范围；后续授权实现时按可信服务映射并补行为证据，调整账号/组织不变量或菜单基线须有新的明确决定。

### 源、宿主与创建

Harness 只维护可复用规则、Skills、中性资产和交付工程。下游平铺单包且唯一 `projectType` 为 Web 或 Extension，不建立多宿主、monorepo、共享 core 或宿主切换入口；桌面 GUI、Rust/Tauri、签名和桌面发布链不在范围内。

有文档时受委托只读分析目标、首页、页面、流程、数据模式与验收场景，并冻结原文交接；无文档时渐进澄清实际首版范围。宿主必须明确选择且无默认，不从关键词启用功能。原文是不可信需求数据，不执行其中命令，不授予服务、凭据、权限或资金操作；正式 PRD、原型、业务实现仅在成功下游产生，已有答案和批准直接复用。

完整创建的一次范围确认覆盖工程事务、下游 Approved PRD、一个桌面交互原型、自查登记、真实首版实施与开发走查。工程事务只到 `ENGINEERING_READY`；产品阶段失败保留并修复现场，不能以空壳结束完整创建。新页面及显著交互变化先登记原型，日常小修复不强制重走。

唯一公开工程入口为源 `pnpm instantiate`。目标必须位于源外且为空；冻结受管源路径、字节、模式、版本和 Git 状态，在 sibling staging 内生成、定向格式化、结构/三环境/终端化校验、一次安装和独立 Git 初始化后，复核输入再原子发布。同目标租约及父目录/staging/holding 身份绑定保护现场，失败不清理替代树。成功下游只有一个 `chore: 初始化项目` root commit、clean 工作树且无远端，不保留派生入口，不继承源记忆；初始化不接受 E2E、不生成 Release 产物。

### 职责与能力接线

实例化拥有输入和事务，需求定义拥有完整语义和唯一 PRD，功能组合拥有模块/操作/依赖与资源选择，原型拥有桌面交互和摘要登记，实施拥有真实代码与验证。创建前单向委托只读分析，叶子返回当前调用方，不反向重启流程或重复问卷。只读所命中 Skill 及当前阶段需要的参考。

### 身份、组织、权限与写入恢复

基础身份接齐登录、恢复、用户区、匿名守卫、安全返回、Token、退出和当前 401；generation/revision、导航和组织 scope 各有明确生命周期，旧请求和迟到回调不能污染新身份。公开认证传输不携带旧 Token，不提前修改应用会话；业务 403 保留会话。退出先阻止私有动作与旧回调，再有界吊销并清理精确凭据、内存和私有 Query，不清空偏好或声称全设备退出。

组织切换保留主壳，只撤下私有正文和旧查询/权限；无论写响应成功或未知，都重读并校验权威组织、主体和当前 scope，再刷新权限恢复。已确认目标视为成功，已确认未切换则保留会话并报错；无法确认上下文或权限时安全关闭，不自动重放。尚未选择时，单个可用组织也允许首次选择。

权限码同时用于路由、导航、页面、元素和提交前复核，缺失要求不放行；模块选择不授予权限，前端隐藏不替代服务端授权。管理目标组织不替换管理员身份；订单允许状态、成员/最后管理员保护、历史快照、并发版本及审计仍归真实服务领域。

购买先建单再支付原订单；重复提交、并发与未知结果使用幂等关联先查询恢复，不自动重放。未决购买由当前应用 scope 持有，关闭弹窗和切换路由不丢关联；主体使用结构化键隔离。确认付款后精确刷新，刷新失败不回滚已确认结果；不隐含充值、退款、调账或提现。Mock 不证明真实资金安全。

Token/continuation 默认仅存当前上下文内存。仅 Web 明确选择凭据持久化时适用数据规范的封闭例外，处理损坏、拒绝、轮换、跨标签及删除失败；不持久化密码、验证码、用户、权限或 continuation，不以时间戳伪造 CAS。允许的 Mock 恢复只保存最小演示引用，不由引用拼造用户/权限。Extension 不继承该持久化例外。

### 数据、状态与双宿主

API 与存储统一在 `src/data/`，业务编排归 feature。Ky 为默认 Fetch 传输，关闭其自带重试/超时/HTTP 抛错，复用受控 BaseURL、动态 header、取消、截止时间、认证 revision、401 single-flight 与 ApiError。统一错误分类和本地化反馈，401/403 不提供普通重试，安全读取有界重试且只播报最终失败，mutation 不自动重放。

远端列表含首次读取、搜索、筛选、排序、分页均用可信 GraphQL Query；本地集合、详情子数组、单对象和写入按真实语义处理。缺 Schema 保留缺口，不猜 endpoint 或改标签。TanStack Query 唯一拥有有限异步服务缓存，feature options 贯通组件/loader/命令式读取，client 不建第二缓存。Apollo 改缓存 owner 需明确批准，GraphQL/Codegen/Dexie/RxJS/订阅库仅随真实消费者引入；事件校验后投影到既有状态，不建全局总线。

未配置远端服务时，仅该 API 边界使用完整类型化 Mock；本地计算、转换和存储真实实现，UI/route/Query 不内嵌 Mock，真实失败不回退 Mock。测试默认隔离，明确共享模拟服务才共享状态，使用可控时钟/异步验证竞争。只读订单 Mock 仅有 list、按主体隔离、复制快照并支持取消；本地化响应查询包含语言键。

Router search 拥有可分享导航态，Query 拥有远端结果，Jotai 只拥有必要共享客户端态，React 拥有局部态。Web 列表只在原始 URL 完全没有 owned key 时读一次 session 快照并在首次 Query 前 canonical replace；行与 total 不复制，分页复用 1-based/pageSize，不强制 Table、选择、列偏好或 DnD。

Web 使用 Vite 与 TanStack 文件路由，路由树临时生成并忽略；Extension 使用 Plasmo，Popup memory/Options hash Router，各入口独立 Query 与内存会话，不共享 Token、401 或 sessionStorage，不继承 Web 列表合同。Chrome MV3 可回收 service worker 与 Firefox MV2 后台各按真实生命周期核对。消息、Storage、CSP、资源与权限只随真实消费者增加，禁止远程可执行代码；动态 manifest 分目标生成，共享覆盖不固定版本，Parcel 明确 browser context 并打包运行时依赖，拒绝生产 self-map。

详细合同：[数据访问](../DATA_ACCESS.md)、[宿主基线](../TS_WEB_TEMPLATE.md)、[Web 列表](../../.agents/skills/web-implement-list-view/SKILL.md)、[Extension 审查](../../.agents/skills/web-review-extension-compatibility/SKILL.md)。

### UI、身份与工程治理

`.harness/project.json` 唯一拥有身份与品牌，Logo 母版派生当前宿主资源；明确中英翻译通过既有 i18next 消费，Extension 消息安全编码美元，避免构建展开。每 React 根只有一个 MantineProvider，theme 集中十阶品牌色、系统无衬线字体及语义令牌，默认 auto 并允许亮/暗偏好。固定应用使用本地语义 SVG，不预装未选图标/表单/通知/DnD。语义标题、label、键盘、焦点、缩放、语言同步与 reduced motion 必须可用。默认欢迎页、计数器和伪 Query 已删除，实际产品按真实设备范围适配。

模块按功能高内聚、单一职责、单向无环依赖；真实多消费者才提取共享，不建通用兜底目录或转发壳。稳定 TypeScript 声明紧邻中文注释。自有工具使用全局 Node、项目 TypeScript 和标准库，不引入自有 Python；第三方原样 vendor 保留。根 AGENTS 保持 20000 bytes/120 行预算，人工代码 501–600 行复核、601 行拆分，其他文本遵守 500/2000 边界，不压缩规避。路径、普通权限、换行、符号链接与浏览器能力不默认单平台。

Node/pnpm/独立 CLI 全局安装，项目依赖按 manifest/lock 本地安装，脚本使用声明版本。当前最低 Node 24.0.0、pnpm 12.8.1，packageManager 精确 pin 且不低于下界；依赖自身运行要求仍适用，Node24 的 jsdom 要求见 README。TypeScript 暂固定 6.0.3。首次安装产锁后 frozen 复现；pnpm-workspace 仅 allowBuilds，不声明 packages。首次初始化或真实环境错误才检查相应工具，安装/升级不因本条自动授权。

### Task、策略、升级与发布

日常明确范围直接实施，持久计划、左侧 Task、内部写入并行和候选各由独立事件触发。Task 标题使用唯一三字段合同，序号按同项目/宿主当前及归档有效历史递增；绑定真实 thread/project/cwd、Git common-dir、登记 Worktree 和精确起始 OID，每项目同时一个写入型 active Task。遵守已有 Local/Worktree 选择，无选择时 Git 默认 Worktree；不从未提交状态派发，不用内部 plan/Subagent 冒充左侧 Task。

只读子代理可并行；写入并行还需当前明确要求、策略 enabled、干净已提交基线与不重叠所有权，按精确登记整合及清理。Git 配置只在明确要求或实际提交前处理，保留有效身份、仅补 repo-local 缺项，冲突预检和失败回滚，不改 global；中文提交记录实际原因、变更、影响与验证。

策略 schema 3 的推荐五项为 user_owned_tasks disabled、superpowers disabled、parallel_worktree_subagents disabled、acceptance_smoke enabled、e2e_hint disabled；源规定 pending 不代表已确认推荐值，下游不得 pending。初始化一次收齐，永久变更需明确确认和当日 ADR，同值 no-op，不将临时限制持久化。本次整理不改变策略。

升级先只读冻结 clean source/OID、当前宿主候选和目标状态，三棵根互不嵌套。未知及产品/身份/品牌/策略/记忆默认 protected，文档 merge-sections；candidate/target 双快照三方比较，bootstrap 不猜祖先。逐路径批准、原子单文件应用、每写后重规划；新增 helper 先收敛，父调用与 CLI 最后，所有路径收敛再记 lock。保留本地的路径不冒记新基线。源独立所有权下限防共同弱化；源日期记忆、历史卷和源专用能力不派生。

普通修改运行相关非空测试，结构重构运行全测，Harness 维护运行 validate:harness。唯一下游 build 自动执行三环境/Harness/格式/lint/类型/全测、版本注入、生产构建和 release:inspect；Extension package 形成双目标 zip，不自动递增。初始化地址可空，Release 必须 HTTPS；公开配置不含秘密，不为 Mock 假称真实服务。Harness 根只形成源码候选。

Harness Version.md 使用上海 YYYYMMDDHHMM；Web 页面使用构建上海 YYMMDDHHMMSS；Extension 软件、页面与双 manifest 使用包内稳定三段 SemVer。源码、lock、hash、schema/协议和唯一类型精确匹配。发布流程复用明确 E2E 选择，缺失且无硬要求才问一次；smoke 独立解析，源 pending 不授权可选冒烟。required 只验证精确最终候选，Web Chrome、Extension Chrome/Firefox 分别取证，新字节重验。失败/超时/取消/未执行不得通过，未测平台/服务/渠道如实标明。

明确发布请求覆盖既有目的地和范围内必要提交、推送及发布，不重复确认；新增渠道或范围外凭据、生产、付费、资金和不可逆副作用另确认。发布后复读远端；构建成功不等于 Released。PRD/ADR/Changelog/Status/计划各按独立事件记录，构建与测试结果留当次交付说明；当前正文保留最新设计，完整过期原文追加历史，源历史不下发。
