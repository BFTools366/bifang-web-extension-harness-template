# 验证记录

新创建以 [Workspace 合同](WORKSPACE_TEMPLATE.md) 为准：根拥有 Git、锁与产品事实，成员内部单一宿主；已有服务必填开发 BaseURL，需要服务且明确没有现成服务时创建 Go 成员，确定纯本地时自动 none。下文旧平铺单包限定只适用于既有独立前端；发布与验收必须显式选定一个成员、根 Git 与精确候选。

## 原则

- 只报告真实执行的命令、候选、环境、结果和未覆盖范围；未运行写“未执行”，未验证写 `Unverified`。
- 日常开发只运行本次变化需要的相关非空测试或最小替代检查，不自动追加格式、lint、类型、全仓检查或构建；行为保持的结构重构运行全量测试。
- 源 Harness 完整验收验证 验证器、维护辅助脚本、Web 或 Extension 与已有/自建服务条件的源外实例化结果和当前发布规则，不把模板源码、Mock、开发预览或内部函数调用当作最终产物证据。
- Web 最终候选必须是当前源码经唯一 `pnpm build -- --e2e=enabled|disabled` 生成的 Vite `dist`；Extension 还需由同一正式环境配置 生成当前 Chrome MV3 和 Firefox MV2 两个 zip。
- 同一发布流程复用已明确的 E2E 选择；重建或打包后重新验收新字节；持久 `e2e_hint` 只提供建议默认值。完整候选验收还独立解析 `acceptance_smoke`：硬要求优先，否则 `enabled` 运行有边界的真实浏览器冒烟检查（Web 使用 Chrome，Extension 逐个使用 Chrome/Firefox），`disabled`/源 `pending` 不主动运行；E2E 与 smoke 任一为 `required` 时都只针对精确候选执行。
- 有用户要求的活动 Work Plan 时，相关 Todo 必须全部完成；没有 Work Plan 不阻断用户明确要求的完整验收。
- 单元测试可隔离外部依赖，但不能替代真实候选运行。必需门禁失败、超时、取消或已选未执行都会拒绝候选并返回开发循环。
- 明确发布请求覆盖既有目的地及范围内的必要提交、push 和发布步骤，不重复确认；验收通过本身不触发外部发布，新增目的地或范围外副作用才补充授权。

## 当前矩阵

| 层级             | 必需证据                                                                                                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 源结构           | `pnpm validate:harness`：文件、Skills、日期记忆、Markdown 链接、策略、注释、行数与初始化静态契约                                                                           |
| 源行为           | `pnpm lint`、`pnpm typecheck`、非空 `pnpm test` 与相关辅助脚本的隔离 Git 回归                                                                                              |
| Web 实例化       | 源外空目录、单一 `projectType=web`、无派生入口、三环境有效、已登记成员；初始化无 Git，后续启用时仅归 Workspace 根管理                                                      |
| Extension 实例化 | 源外空目录、单一 `projectType=extension`、两浏览器最小权限、独立入口代码 Router、无 Web 文件路由生成器/另一宿主、已登记成员；初始化无 Git，后续启用时仅归 Workspace 根管理 |
| Web 候选         | 唯一正式构建、版本注入、敏感信息扫描、Vite `dist`，以及当次适用的真实 Chrome 证据                                                                                          |
| Extension 候选   | 唯一正式构建、版本/manifest/权限/敏感信息检查、相同配置的 zip，以及当次适用的真实 Chrome/Firefox 逐目标证据                                                                |
| 源发布           | `Version.md` 为 上海时间版本 `Released`，提交完整，工作树干净，`HEAD == origin/master` 且远端回读一致                                                                      |

桌面客户端、Rust/Tauri、桌面打包、签名、公证和桌面发布验证不属于本仓库。

工程创建事务完成只证明基线就绪；完整创建须在下游实现并验证确认首版。首版的开发浏览器走查与本文件最终候选验收分别取证，不能互相代替。仅要求创建时不为构建伪填 Release BaseURL；需要 dist/zip 才形成真实候选并执行对应门禁。
