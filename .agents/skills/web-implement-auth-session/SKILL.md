# Web Harness：实施身份会话

为当前认证功能维护唯一会话拥有者，完成状态转换与实际接线；完成后返回调用方，不重启需求、设计、HTTP 接入或候选验收。

## 触发与输入

- 仅已初始化下游涉及登录接受、冷恢复、身份校验、退出、当前 401、既有凭据轮换或迟到异步结果时应用。源 Harness 只维护本 Skill 和中性模板。
- 复用已确认的身份操作、可信 API 契约、当前宿主/执行上下文、会话与 HTTP/Query 拥有者、持久化授权、受影响入口及有效验证。只补本次转换依赖的缺项，不重新选择模块或组织模式。
- 领域不变量只读 [身份知识](../web-compose-capabilities/knowledge/identity.md) 的命中章节；HTTP/凭据、401/403 和存储例外分别消费 [数据访问规范](../../../docs/DATA_ACCESS.md) 对应语义章节。参考模板不证明真实服务支持刷新、吊销或跨上下文共享。

## 实施与归属

1. 沿当前入口追踪唯一会话状态机，明确匿名、恢复/校验、可用和失效阶段，以及凭据、私有 Query、请求/订阅、导航回调的拥有者。不创建第二套会话，不把身份和权限复制成独立缓存。
2. 在既有认证 feature 中实现或修复会话 generation 与异步提交权；每次 await 后复核当前转换归属。导航取消与会话失效分开，迟到登录、恢复或 401 不得覆盖或清理后来会话。
3. 按已确认契约校验并接受凭据，通过既有 HTTP setter/失效回调装配传输；恢复成功后才公布可操作身份。区分明确失效、无响应网络失败、取消和本地错误，按身份知识处理，不从任意 2xx、JWT 解码或网络错误推导授权。
4. 退出立即阻止新私有操作、使旧结果失效，并清理当前拥有的凭据、continuation、私有 Query 与附属上下文，本地失效和恢复阻断不等待远端。再用捕获的旧凭据按服务合同尝试有界处置，完成后复核归属。保留语言/主题；远端失败仍完成本地退出，持久项删除失败阻止旧记录重新恢复。未公布签发只能窄处置，不能误伤后来身份。
5. HTTP client 的 Header、Token revision 与 401 single-flight 继续由 client 负责；本 Skill 只接线和处理当前会话转换。凭据存取、校验和迁移委托 `$web-implement-browser-storage` 并传入既有授权及数据合同；权限判定由 `$web-implement-access-control` 消费已确认身份，领域允许状态不在此改写。
6. 已选注册、找回、轮换或跨标签页分支才读取和适配对应知识；未确认的能力返回契约缺口，不默认新增 refresh、写重放或 LocalStorage。Extension 明确当前执行上下文和真实 owner，跨上下文共享只按已授权消息/宿主存储合同实施；宿主边界变化委托 `$web-review-extension-compatibility`。
7. 通过已有订阅、HTTP adapter、私有缓存清理和安全导航回调接入真实消费者；UI 设计、能力选择及真实 endpoint 迁移留在各自入口。可按需适配 [独立会话协调器](../web-compose-capabilities/templates/identity/session.ts.txt) 与 [应用接线](../web-compose-capabilities/templates/application/wiring.md)，不并列保留旧 owner。

## 验证与返回

- 运行本次相关非空回归，覆盖成功转换及最高风险失败：迟到登录/恢复/401、新登录替代旧工作、恢复网络失败、退出吊销失败、本地清理失败及私有缓存隔离。只测试实际选择的持久化、注册/找回、组织与跨上下文分支。
- 报告受影响入口、唯一会话 owner、转换与副作用接线、实际测试及未确认契约。测试替身不能证明真实账号、浏览器或最终候选；真实接入与候选事件返回当前调用方。
