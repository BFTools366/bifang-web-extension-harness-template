# 操作审计知识库

按真实服务能力选择审计查询、筛选与详情；说明管理写入需要的服务审计关联，不自动生成角色管理、组织、订单、钱包或客户端审计写入。

服务端拥有权威审计记录。客户端结构化日志、离线演示和保存成功后单独补发的浏览器事件都不能替代服务审计一致性。

## 服务事实与边界

| 范围     | 核对事实                                                | 边界                                    |
| -------- | ------------------------------------------------------- | --------------------------------------- |
| 审计记录 | 稳定关联、可信操作者、对象/组织、动作、时间、原因、结果 | 字段与可见性来自真实服务                |
| 查询范围 | 操作者权限、平台/组织/对象范围、服务筛选/分页           | 选目标不改变操作者身份                  |
| 业务关联 | 请求、实体、原单/尝试等实际存在的公共关联               | 不把 request_id直接当业务幂等或审计凭证 |
| 一致性   | 业务结果和审计保留关系、索引延迟与查询权限              | 审计读取失败不重放业务写入              |
| 脱敏     | 服务允许显示的字段与秘密材料禁入规则                    | 不默认批量导出全部客户数据              |

不提供编辑、清空、删除审计入口，不伪造历史。保留策略由服务与真实产品范围确认，不因前端“停用”或删除对象级联清除历史。

## 审计查询 SOP

1. 以现有可信身份读取真实权限和可查询范围。没有审计查看权时隐藏入口且直达拒绝；没有该 UI 不改变服务端管理审计职责。
2. 按已确认的时间、操作员、对象/组织、动作、结果等条件读取。展示明确 locale/时区、目标和筛选范围，页内数量不冒充全量。
3. 详情显示可信的操作者、动作、原因、结果与允许的关联记录。未知动作/结果保持可解释状态，不自动归类为成功。
4. 凭据、密码、验证码和支付秘密不进入列表/详情/客户端日志；服务敏感字段按真实脱敏合同处理，不输出未经许可客户资料。
5. 读取失败保留筛选和原业务已确认结果，提供重试。索引延迟时显示待同步；不能把尚无审计结果解释为业务未执行。
6. 与已选组织、订单、钱包或权限页面关联时传递稳定公共对象/查询 scope，不读取其他模块私有状态；无该模块或无权限时省略链接，不自动生成页面。
7. 退出、目标或权限变化隔离旧数据/回调，不能把前一组织审计展示给新组织。

## 管理写入的审计关联

仅在已有业务模块选择管理写操作时应用：核对操作者、目标、scope、动作、服务所需原因、版本/幂等与结果查询，由服务保证审计与业务结果的一致性。前端负责收集必要原因、展示影响和结果，不成为审计账本所有者。

业务结果未知先查询原操作，不能为了补审计重复写入。业务确认成功而审计查询失败时保留业务成功，只重试审计读取；异步索引按照服务一致性说明显示，不手工造成功记录。业务失败/拒绝是否留审计与敏感信息范围均以真实服务为准。

用户选择审计查询不授权任何业务写操作、客户资料全量导出或生产访问。

## GraphQL 列表强约定

审计记录、动作候选、可查询主体等远端集合查询统一使用 GraphQL，覆盖无条件首载、时间/条件筛选、搜索、排序与分页。单条详情按真实契约；Schema缺失是缺口，已有 REST列表如实标记不符合，不自动成为例外。纯本地筛选现有记录不虚构远端能力。

时间范围、排序稳定性、游标/分页、一致性与可见字段先有可信合同；不能从已有基础分页形状推断服务已支持审计。

## Web 与 Extension

Web按实际列表、Router/Query与 i18n合同，保持筛选/返回位置、加载/空/拒绝/错误状态及键盘操作。Extension在真实 Popup/Options等surface使用自己的导航与消息/状态owner，不继承 Web文件路由或列表Skill，不为审计默认加后台入口/权限。

Chrome MV3和Firefox MV2的实际请求、上下文生命周期与权限拒绝分别验证；业务审计权限和浏览器 permissions不是同一授权。审计模块不授予凭据持久化，更不继承 Web LocalStorage例外。

## 验证

覆盖服务记录来源和字段脱敏、操作者/目标范围隔离、无权直达拒绝、筛选分页/明确时间、未知状态、退出/撤权后的迟到结果、索引延迟；关联管理写入时覆盖“业务成功而审计读取失败”只恢复读取、不重放写入。

当前没有真实服务时只报告知识/设计/Mock检查，不声明服务器审计、数据库保留或真实浏览器已验证。构建、完整候选、发布与新增导出均按各自独立触发范围执行。
