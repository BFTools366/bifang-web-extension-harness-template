# 组织切换固定设计与接线

- 路由/槽位：/organization。
- 固定设计：固定当前组织选择器与可切换列表，显示加载、空、拒绝和错误；不把管理目标当登录身份。
- 代码接线：选择器消费 OrganizationApi；切换期间撤下私有正文，清理旧作用域查询并刷新权限；未知切换结果不能继续使用旧组织。
- 操作边界：要求基础用户，不自动加入权限、邀请、成员写入或代登录。

`OrganizationContext` 为组织页、账号菜单和侧栏提供同一 Query；scope 与语言进入 key，结果标记为私有。当前名称只从可信上下文计算，不复制到第二仓库。菜单导航只在已接线且有页面权限时出现；侧栏紧凑状态保留可访问全名。加载、切换、无组织和不可用分别表达；没有不同于当前组织的可选项时禁用切换，未选择时即使只有一个选项也可首次选择。切换开始只撤下私有正文，外壳和账号触发器持续存在。无论写响应成功或未知，都重读并校验权威组织；确认目标后恢复，确认未切换则保留已确认会话并报错，无法确认上下文或权限时安全关闭，不自动重放。

具体品牌、文字、数据契约和可信权限码消费下游唯一 PRD；不改变固定布局、路由、会话或 API owner。代码资产由[应用装配器](../application/files.ts)按已选操作返回，设计与接线清单见[应用接线合同](../application/wiring.md)。只复制页面或函数不算接入完成，须验证入口、主流程、最高风险失败及依赖未选时的缺席。
