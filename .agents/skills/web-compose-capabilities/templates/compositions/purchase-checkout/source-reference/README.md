# 商品、订单与钱包的中性设计参考

[打开离线参考](index.html)。从 `bifang-mini-cb` 的商品 v2 交互原型提取同屏选购结构，包含费用概览、分类、商品选择、钱包确认、订单筛选/分页、原单支付/查询和钱包流水。来源没有相应产品 React 实现，本目录仅为设计参考，不自动安装为下游页面，也不代表来源已选方案。来源路径与摘要见 [提取记录](../../../application/extraction.md)。

- 已移除来源品牌图片、名称、方案标签和评审证据。数据均为虚构 Mock，状态只在页面内存；不联网、不持久化、不真实扣款。固定币种、数量、余额、组织及订单状态只服务演示，不是通用业务合同。
- `demo-data.js` 集中维护双语说明、商品、组织及初始内存服务数据；其他文件分别拥有页面渲染、选择/支付弹窗与本地演示动作，避免把文案或数据复制到各视图。
- 接入代码使用 [应用模板](../../../application/files.ts) 与 [内容替换入口](../../../application/extraction.md)。真实首页由当前需求提供；UI 只消费所选域的类型化 API Mock。更丰富的订单或钱包语义按对应合同扩充，不直接复制演示 DOM 脚本进入产品。
- 原有 [购买最小参考](../commerce-reference.html) 保留独立启用、分类失效和原单续付的专项演示；本目录补充来源的完整费用中心结构，两者均不能代替实际 API、路由或产品验收。
