# API 与业务文档

本包描述已采用服务合同、实际内存协议 Mock。八个认证 REST、两个系统 REST 和只读 GraphQL 已模拟；此包是能力模板的示例协议，不描述真实产品部署。

先读 [API 元数据](api/metadata.md) 的操作目录与差异，再读 [通用结构](api/common.md)，按目标查看接口及已实现流程。

| 业务目标                               | 业务文档                                | API 文档                   | 关系说明                                                         |
| -------------------------------------- | --------------------------------------- | -------------------------- | ---------------------------------------------------------------- |
| 登录、注册、找回、会话恢复、账号与退出 | [账号访问与工作区](business/account.md) | [账号接口](api/account.md) | 仅保留 Mock/测试消费流程；当前无产品 UI，组织/权限是明确模拟扩展 |
| 存活与服务健康                         | 当前无客户端调用方                      | [系统接口](api/system.md)  | 已有可调用 Mock 操作，未编造产品流程                             |

文档不包含客户端代码或本地工程路径。所有报文为虚构说明示例；接口状态、来源合同与模拟支持面分别标注。完整交接使用本包，不能当作联调或最终产物验收。
