# 账户协议模拟流程

## 业务目标与范围

本参考通过内存协议 Mock 和隔离行为测试验证账号、验证码、凭据与组织上下文。当前没有产品页面或导航消费者，也没有真实 HTTP；旧完整工作区示例已退役。以下流程描述已保留的模拟消费者，不能当作产品 UI 完成证据。

## 调用流程

| 步骤           | 条件/动作                  | 接口                                                          | 模拟结果与下一步                                                                               |
| -------------- | -------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 发送验证码     | 目标邮箱及注册/找回用途    | [发送验证码](../api/account.md#v1-verification-code)          | 返回服务规定的重发间隔，验证码用途、目标与期限隔离                                             |
| 注册           | 账号资料、密码与有效验证码 | [注册](../api/account.md#v1-register)                         | 原子建立账号、个人组织及 owner 组织用户，不自动登录                                            |
| 登录           | 隔离的公开账号密码提交     | [登录](../api/account.md#v1-login)                            | 校验签发报文，取得仅同一服务可恢复的独立模拟引用                                               |
| 查询当前身份   | 当前有效引用               | [当前账号](../api/account.md#v1-profile)                      | 校验账号归属，无效、过期与独立服务引用被拒绝                                                   |
| 读取组合上下文 | 已确认身份                 | [账号组合查询](../api/account.md#unversioned-account-context) | 返回账号及默认组织，成员范围与权限仍是明确的模拟服务扩展                                       |
| 找回密码       | 有效找回验证码与新密码     | [密码找回](../api/account.md#v1-password-reset)               | 修改密码并吊销同一服务内该账号会话，失败不假报成功                                             |
| 刷新           | 有效刷新值                 | [刷新](../api/account.md#v1-refresh)                          | 校验用途与有效性并替换服务签发结果，不自动重放业务写入                                         |
| 修改密码       | 已确认身份及旧/新密码      | [修改密码](../api/account.md#v1-password-change)              | 核对旧密码并更新，失败保留原有服务状态                                                         |
| 退出           | 当前有效会话               | [退出登录](../api/account.md#v1-logout)                       | 按合同吊销该账号在同一 Mock 服务内的全部会话，本地退出和私有缓存清理须由产品会话拥有者另行接线 |

## 异常与恢复

- 公开请求隔离旧访问值；Header、报文及原始响应先校验，再交付领域结果，不把协议错误伪装成成功。
- 注册查重失败不消费正确验证码；找回、刷新和改密分别验证用途、过期、错误凭据及状态隔离。
- 显式共享服务实例才共享会话；服务重置清除验证码、临时账号、令牌与会话，重置前迟到结果不能再次提交。
- 精确存储参考单独校验损坏、拒绝、ABA 变化、锁内代次与写后核实，不提供第二套登录/退出协调器。

## 设计思路与边界

服务状态由唯一内存实例拥有，协议适配与存储访问各自验证边界。模拟引用与原始令牌分开，不能从浏览器保存的引用重建服务授权。真实会话、页面、导航、偏好与权限呈现由采用该参考的产品分别实现并验证；本包不声称已联调、已上线或已通过真实浏览器验收。
