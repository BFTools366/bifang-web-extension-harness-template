# 账号访问与工作区流程

## 业务目标与范围

访客登录或找回密码后进入可访问的工作区；新注册账号同时建立个人组织和 owner 组织用户，登录后进入个人组织；账号用户可查看当前身份、退出并在演示服务提供的组织间切换。远端全部为内存协议 Mock，本地表单、导航、偏好与精确存储实际运行。购买页面、真实组织授权和真实 HTTP 尚未实施。

## 调用流程

| 步骤       | 条件/动作                                            | 接口                                                          | 结果/下一步                                                                                                     |
| ---------- | ---------------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 发送验证码 | 注册或找回用途，邮箱和用途绑定；重发等待服务返回秒数 | [发送验证码](../api/account.md#v1-verification-code)          | 演示码仅在模拟模式显示；更换目标不复用旧码                                                                      |
| 注册       | 用户名、邮箱、密码及有效验证码                       | [注册](../api/account.md#v1-register)                         | 返回账号并清除秘密输入、回登录，不自动建立会话                                                                  |
| 登录       | 公开提交账号密码，不携带残留访问凭据                 | [登录](../api/account.md#v1-login)                            | 完整校验签发结果后取得独立演示引用；精确保存成功后恢复身份                                                      |
| 恢复与导航 | 已有引用、直达或受保护页面导航                       | [当前账号](../api/account.md#v1-profile)                      | 每次新鲜校验；只有同一服务已有记录可恢复，不从引用重建身份                                                      |
| 页面上下文 | 账号校验成功后                                       | [账号组合查询](../api/account.md#unversioned-account-context) | 读取账号与默认组织；成员组织和能力另由演示服务确认，全部就绪后显示私有正文                                      |
| 找回密码   | 邮箱、找回验证码、新密码                             | [密码找回](../api/account.md#v1-password-reset)               | 成功吊销同服务该账号会话；清除属于本次提交的本地会话，返回登录                                                  |
| 退出       | 用户明确退出                                         | [退出登录](../api/account.md#v1-logout)                       | 先隐藏私有内容、精确清理引用和私有数据并发布匿名或阻断状态，再尝试有界吊销；存储冲突跳过远端吊销，保留语言/外观 |

显式会话能力还实现了[刷新](../api/account.md#v1-refresh)和[修改密码](../api/account.md#v1-password-change)，当前没有对应页面入口，也不自动刷新或重放。刷新只提交内存刷新值，成功后协调保存替换引用；改密失败保留会话，确认成功后退出。它们不构成已上线用户操作入口。

组织切换没有来源服务接口。当前仅调用同一演示服务的本地扩展，校验成员范围并返回权威组织，随后恢复上下文；结果未知先重新确认，不在浏览器中直接改组织并开放权限。固定演示账号拥有明确的演示成员列表，新注册账号不继承别人的演示组织，只拥有自己的个人组织与 owner 组织用户。权限按当前组织用户 ID 读取，测试菜单只授予固定测试组织用户。登录返回目标、直达、菜单和撤权分别执行同一访问规则。

语言与外观设置集中在无需登录的公开设置页，不初始化认证或监听认证记录变化；偏好操作不调用远端 API，不与认证引用同存，保存失败不伪报持久保存。认证页底部、工作区侧栏底部与资料页通过导航进入设置，返回保留原页面与安全业务目标。离开认证页销毁输入，不保存密码或验证码草稿；认证字段保留标签并提供占位提示。

## 异常与恢复

- 登录错误留在表单，不清理后来建立的其他会话；注册查重失败不消费正确验证码，非法昵称在写入前拒绝。
- 用户、组织或权限尚未确认时不显示私有正文；离线或超时保留引用并提供恢复，不能拼造授权。凭据校验明确失败时清理本应用会话，普通业务权限不足不注销新身份。
- 同作用域普通导航保留工作区外壳及已确认内容；取消旧导航不能中断已确认失效的清理或新组织恢复。迟到结果不得覆盖新登录。
- 持久化写入和精确删除均核实结果；跨标签变化重新读取当前记录，冲突阻断过期写入。共享演示必须显式使用同一服务；独立标签页默认独立服务，完整刷新或重置后旧引用失效，需要重新登录。
- 服务重置清验证码、临时账号、密码变更、令牌和会话；重置前请求及迟到响应取消。取消不播报普通失败，也不公布会话。
- 退出先使本地身份失效并精确删除，再在非存储冲突时尝试有界远端吊销；远端失败不恢复本地身份，也不声称服务已吊销。精确删除失败提供清理重试；临时未公布引用的清理不吊销其他会话。

## 设计思路与边界

依据已确认账号操作与会话约定，先完成身份和必要作用域再显示内容；独立持久引用与内存令牌避免把演示值当作真实凭据。服务状态由一份模拟服务拥有，客户端只校验报文及编排；上述行为不能证明真实服务权限、浏览器跨域或生产安全成立。默认组织、演示成员组织与当前作用域分别处理，不从账号状态、负责人字段或令牌内容推导正式权限。
