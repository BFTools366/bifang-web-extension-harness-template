# 订单固定设计与接线

- 路由/槽位：/orders 与购买确认。
- 固定设计：固定订单列表展示订单号、服务金额和状态；购买确认显示已选商品与服务订单金额。
- 代码接线：OrdersApi 隔离读取和创建；购买协调器保存原订单与独立幂等关联，未知结果仅查询恢复；付款成功后重取订单与钱包。
- 操作边界：只读订单不默认加入商品、钱包或身份；创建/购买要求基础用户。真实接口另按服务确认。

具体品牌、文字、数据契约和可信权限码消费下游唯一 PRD；不改变固定布局、路由、会话或 API owner。代码资产由[应用装配器](../application/files.ts)按已选操作返回，设计与接线清单见[应用接线合同](../application/wiring.md)。只复制页面或函数不算接入完成，须验证入口、主流程、最高风险失败及依赖未选时的缺席。
