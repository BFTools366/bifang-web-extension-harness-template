# 钱包与支付固定设计与接线

- 路由/槽位：/wallet 与购买确认。
- 固定设计：固定钱包页展示当前主体余额及币种；支付在订单确认中完成，不添加充值、退款或调账。
- 代码接线：WalletReadApi 只读；选择 wallet-payments.pay 才装配 WalletApi.pay。付款使用同一用户、订单、钱包和原幂等关联。
- 操作边界：钱包操作要求基础用户；选择付款才要求订单读取。Mock 的扣减不代表真实资金操作获授权。

具体品牌、文字、数据契约和可信权限码消费下游唯一 PRD；不改变固定布局、路由、会话或 API owner。代码资产由[应用装配器](../application/files.ts)按已选操作返回，设计与接线清单见[应用接线合同](../application/wiring.md)。只复制页面或函数不算接入完成，须验证入口、主流程、最高风险失败及依赖未选时的缺席。
