# 应用主界面固定设计

主界面从已有客户端提取品牌、持续导航、顶部账号/偏好区、路由正文和构建版本。Web 多页使用可收起侧栏与窄屏导航，单页和 Extension 使用紧凑导航；Web 使用既有文件路由，Extension 使用 Popup memory / Options hash 代码路由。

首页正文由已确认需求实现并以 HomePage 提供；装配器拒绝缺失正文，不生成欢迎页、计数器或默认占位功能。每个页面拥有实际 URL 和本地化标题，语言/主题沿用当前工程。

采用用户能力后，在同一主界面接入当前用户与退出；登录页位于公开路由，全部私有页面在正文读取前完成身份校验。采用权限后，导航、路由、元素和动作消费统一权限要求。采用购买后，商品、订单、钱包与最基础身份组成连续流程。

已选能力保持各自固定设计；原型将这些组件和真实首页内容组合成一个桌面交互流程，自查登记后实施，不重新发明登录、账号区或购买布局。

来源层级、可替换文案/页面和 Mock 数据边界见 [提取与定制](extraction.md)。品牌只消费当前项目身份，结构复用不固化来源业务正文。
