# 应用主界面固定设计

组织导航子项只随已选操作存在：完整协作预设提供组织设置、成员管理和角色管理，本人邀请在切换组织弹窗处理；明确收敛为账号核心且未选管理或协作时，不显示整个组织管理分组，不补回已取消的入口。账号、自有组织、有效成员及个人设置仍保留。

主界面复用品牌、持续导航、顶部账号区、路由正文和构建版本。Web 默认左侧包含工作台、“组织管理”一级分组与底部设置；分组下仅“组织设置”“成员管理”“角色管理”三个二级入口，各按读取权限控制。管理子项按可信权限 code 显示，无可见子项时隐藏分组。账号资料和当前组织卡片不进侧栏；额外产品导航按需求。Extension 保留相同层级语义，以紧凑导航呈现。

本设计记录已确认的账号与组织基线。当前代码资产尚未覆盖全部目标，差异以[接线合同](wiring.md#当前装配器与目标规范的差异)为准，不因设计确认声明生成器已实现。

首页正文由已确认需求实现并以 HomePage 提供；装配器拒绝缺失正文，不生成欢迎页、计数器或默认占位功能。每个页面拥有实际 URL 和本地化标题，语言/主题沿用当前工程。

完整用户方案的右上账号触发器固定为头像、昵称和展开指示；头像缺失用姓名首字，长姓名保留可访问全名。展开顺序固定为：

1. 触发器只显示一个可信昵称（否则用户名），菜单不重复姓名或邮箱，所有条目统一无图标。
2. “切换组织”：打开所有已加入组织的弹窗，当前项禁用，同目标 no-op；本人邀请在弹窗内处理，接受后保留当前选择。
3. “个人设置”：打开账号级资料弹窗，邮箱只读、修改全局昵称，成功后刷新可信身份。
4. “修改密码”：打开改密弹窗，独立输入当前、新密码及确认；成功撤销旧会话并返回登录，未知结果重新登录核对。
5. 分隔线及危险色“退出登录”。

语言和主题只在可返回的全屏公开设置页，Web 入口位于侧栏最下方；Extension 使用独立设置导航。缺少资料或邀请的实际页面/API 时，实施入口报告未完成项，不能用空菜单或当前注入槽宣称完整用户系统已交付；也不能从示意文案生成服务契约。

组织名称、切换弹窗和组织管理共用唯一可信 Query，不能在组件或 Storage 复制档案；组织上下文不注入侧栏。布局保留唯一 `content` 正文与右上账号触发器，Header 不展示组织卡片，组织信息只在业务正文与弹窗显示。切换期间保留外壳，撤下旧组织正文、草稿、菜单和业务弹层；账号入口仍可用于退出或必要恢复。只有新组织、成员和权限全部确认后才放行业务；超时或结果未知显示组织待确认，禁止混用旧数据/权限。迟到回调不能干扰新上下文。

语言与外观统一进入脱离私有外壳的全屏公开 `/settings`，不触发身份恢复、组织读取或权限门禁；提供返回入口；设置导航与账号菜单分开。认证页底部只保留一个低强调文字设置链接，不使用齿轮按钮，字段保留可见标签并提供本地化 placeholder。更改即时生效；返回只接受已声明页面及安全业务目标，并按 Router 的 pathname、defaultParseSearch(search)、hash 分别导航；不得将完整 URL 放进 to 或用 Object.fromEntries(searchParams) 改写数值/JSON 形态字符串，来源随历史项传递，表单凭据不进入 URL 或存储，离开表单后清空。直接设置页按已选身份能力返回登录或首页。Web 文件路由与 Extension Popup memory / Options hash 各自拥有公开设置路由，不增加跨入口状态或权限。

登录页位于公开路由，完整用户方案在私有正文读取前完成账号、组织、成员与实际权限校验。采用注册时，默认要求邮箱、密码及邮箱验证码；自建服务未接邮件时采用开发投递回显，用户名和组织默认名由服务生成。服务原子创建账号、自有组织和 owner 成员；注册后自动登录与否按真实服务合同处理，不由原型直接进入演示决定。采用权限后，导航、路由、元素和动作消费统一权限要求。采用购买后，各能力页入口按已确认导航需求组合，不自动占据默认侧栏。

已选能力保持各自固定设计；原型将这些组件和真实首页内容组合成一个桌面交互流程，自查登记后实施，不重新发明登录、账号区或购买布局。

来源层级、可替换文案/页面和 Mock 数据边界见 [提取与定制](extraction.md)。品牌只消费当前项目身份，结构复用不固化来源业务正文。

组织管理三页、11 项权限及读取依赖、昵称归属、角色保护、迁移与写入恢复统一遵循 [Auth 标准](../../../../../docs/ACCOUNT_OWNERSHIP.md#前后端标准交互与权限表)。同一主体刷新权限时保持编辑实例但隐藏并禁止交互，确认撤权才卸载；业务弹窗在此边界内渲染，不能通过 Portal 逃逸。

所有列表、表格和页脚复用 [UI 标准](../../../../../docs/MANTINE_UI_GUIDELINES.md#标准账号与列表组件)，不复制领域分页控件。弹窗写入及未知结果保持关闭锁，普通关闭保留底层路由与表单草稿。
