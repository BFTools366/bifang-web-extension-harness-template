# 应用主界面固定设计

主界面从已有客户端提取品牌、持续导航、顶部账号区、路由正文和构建版本。Web 多页使用可收起侧栏与窄屏导航，单页和 Extension 使用紧凑导航；Web 使用既有文件路由，Extension 使用 Popup memory / Options hash 代码路由。

首页正文由已确认需求实现并以 HomePage 提供；装配器拒绝缺失正文，不生成欢迎页、计数器或默认占位功能。每个页面拥有实际 URL 和本地化标题，语言/主题沿用当前工程。

采用用户能力后，右上使用头像、昵称和展开指示的账号菜单，按多组织切换、已选且当前 owner 的组织管理、已接线账号设置、分隔线和危险色退出组合。语言和主题只在设置页；已有侧栏时设置位于最下方，单页和 Extension 使用独立设置导航。头像缺失用姓名首字，长姓名保留可访问全名。账号设置是可注入的真实菜单项，不自动创建资料页或 API。

布局提供 `content` 正文与 `context(compact)` 侧栏上下文槽位。组织名称与状态由组织页、菜单和侧栏共用查询，收起后保留有名称的组织入口。切换期间持续保留外壳和账号触发器，只替换私有正文；身份或 scope 变化关闭旧菜单及业务弹层，迟到回调不能干扰新上下文。

语言与外观统一进入脱离私有外壳的全屏公开 `/settings`，不触发身份恢复、组织读取或权限门禁；提供返回入口；设置导航与账号菜单分开。认证页底部只保留一个设置入口，字段保留可见标签并提供本地化 placeholder。更改即时生效；返回只接受已声明页面及安全业务目标，并按 Router 的 pathname、defaultParseSearch(search)、hash 分别导航；不得将完整 URL 放进 to 或用 Object.fromEntries(searchParams) 改写数值/JSON 形态字符串，来源随历史项传递，表单凭据不进入 URL 或存储，离开表单后清空。直接设置页按已选身份能力返回登录或首页。Web 文件路由与 Extension Popup memory / Options hash 各自拥有公开设置路由，不增加跨入口状态或权限。

登录页位于公开路由，全部私有页面在正文读取前完成身份校验。采用权限后，导航、路由、元素和动作消费统一权限要求。采用购买后，商品、订单、钱包与最基础身份组成连续流程。

已选能力保持各自固定设计；原型将这些组件和真实首页内容组合成一个桌面交互流程，自查登记后实施，不重新发明登录、账号区或购买布局。

来源层级、可替换文案/页面和 Mock 数据边界见 [提取与定制](extraction.md)。品牌只消费当前项目身份，结构复用不固化来源业务正文。
