# 账号与组织中的身份固定设计与接线

组织导航子项只随已选操作存在：完整协作预设提供组织设置、成员管理和角色管理，本人邀请在切换组织弹窗处理；明确收敛为账号核心且未选管理或协作时，不显示整个组织管理分组，不补回已取消的入口。账号、自有组织、有效成员及个人设置仍保留。

完整用户方案采用[身份知识库](../../knowledge/identity.md#完整用户信息)的账号、组织与成员基线；本文件同时标明当前可复用认证代码的范围，不能把底层会话资源等同于完整用户系统。

- 目标入口：公开登录、已选注册、右上账号信息与组织菜单。当前 identity.session 代码提供 /login 和主界面用户区，可选 identity.register 提供邮箱注册页；完整 identity.workspace 自动接通资料与改密弹窗，兼容账号地址复用同一弹窗。
- 固定设计：品牌说明与表单分区，窄屏收为单列；登录表单包含账号、密码、提交与错误；已选自建邮箱注册默认收集邮箱、密码与验证码，含重发倒计时及真实错误反馈；未接邮件时开发回执直接显示验证码，真实投递移除回显。所有适用字段提供业务明确的本地化 placeholder，页面遵守 UI 规范的精简文案约束。二者复用 AuthLayout，底部设置采用低强调文字链接。语言/外观集中到无需登录的 `/settings`，即时生效并支持安全返回，离开认证页清空输入。主界面右上固定头像、昵称、展开指示；账号信息、当前组织及操作顺序见[主界面设计](../application/design.md)，账号资料不进入左侧。Web 工作区侧栏包含工作台、组织管理分组与底部设置，额外产品导航单独确认；退出由分隔线和危险色区分。
- 代码接线：登录、恢复、退出使用一个 identitySession；私有路由 beforeLoad 先校验，匿名跳登录并只保留已声明的安全返回目标；HTTP owner 自动携带已接受 Token，当前 401 与退出清理会话。
- 目标接线：完整用户方案在公布可操作状态前同时恢复组织、成员和所需权限；注册必须原子创建账号、自有组织和 owner 成员。账号资料以全局 Account 为所有者，组织内角色以当前 OrganizationUser 为所有者。
- 当前资源边界：独立会话 helper 不依赖组织或权限库，identity.session 不自动生成注册、找回、组织操作或账号资料；选择 register 才生成注册页面，自建邮箱注册自动补齐 verification 发码，已有服务遵循可信合同。采用完整方案时补齐所需领域接线，不能以未自动生成缩减已确认需求。

当前 IdentityMenu 拥有单一显示名触发器、退出与关闭生命周期，不重复邮箱或姓名摘要；AccountMenu 注入切换组织、个人设置与改密的弹窗动作。/account/settings 与 /account/password 是同一资料和改密弹窗的兼容地址；普通菜单操作保留底层路由、分页及草稿。昵称更新后权威刷新唯一 session，改密成功清会话并回登录；低层 session 不自动启用资料操作。

具体品牌、文字、数据契约和可信权限码消费下游唯一 PRD；按[提取与定制合同](../application/extraction.md)替换内容，保留路由、会话及 API owner。代码资产由[应用装配器](../application/files.ts)按已选操作返回，设计与接线清单见[应用接线合同](../application/wiring.md)。只复制页面或函数不算接入完成，须验证入口、主流程、最高风险失败及依赖未选时的缺席。

账号菜单、弹窗和列表的固定外观以 [Mantine UI 标准](../../../../../docs/MANTINE_UI_GUIDELINES.md) 为准：Header 不放组织卡片，单一显示名称，菜单统一无图标；切换组织、个人设置、修改密码使用弹窗，列表复用 ListSurface/ListTable/ListFooter。详细状态归属仍遵循数据规范。
