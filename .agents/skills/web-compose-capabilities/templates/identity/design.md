# 账号与组织中的身份固定设计与接线

完整用户方案采用[身份知识库](../../knowledge/identity.md#完整用户信息)的账号、组织与成员基线；本文件同时标明当前可复用认证代码的范围，不能把底层会话资源等同于完整用户系统。

- 目标入口：公开登录、已选注册、右上账号信息与组织菜单。当前 identity.session 代码提供 /login 和主界面用户区，尚未提供默认账号资料页或注册页。
- 固定设计：品牌说明与表单分区，窄屏收为单列；表单含带本地化占位提示的账号、密码、提交、错误和 Mock 说明，最下方仅放设置入口。语言/外观集中到无需登录的 `/settings`，即时生效并支持安全返回，离开认证页清空输入。主界面右上固定头像、昵称、展开指示；账号信息、当前组织及操作顺序见[主界面设计](../application/design.md)，账号资料不进入左侧。Web 工作区侧栏仅工作台与底部设置，额外产品导航单独确认；退出由分隔线和危险色区分。
- 代码接线：登录、恢复、退出使用一个 identitySession；私有路由 beforeLoad 先校验，匿名跳登录并只保留已声明的安全返回目标；HTTP owner 自动携带已接受 Token，当前 401 与退出清理会话。
- 目标接线：完整用户方案在公布可操作状态前同时恢复组织、成员和所需权限；注册必须原子创建账号、自有组织和 owner 成员。账号资料以全局 Account 为所有者，组织内角色以当前 OrganizationUser 为所有者。
- 当前资源边界：独立会话 helper 不依赖组织或权限库，identity.session 不自动生成注册、找回、组织操作或账号资料。采用完整方案时补齐所需领域接线，不能以未自动生成缩减已确认需求。

当前 `IdentityMenu` 拥有身份触发器、退出及菜单关闭，`AccountMenu` 的 `organization` / `settings` 是注入槽，头像以可选 `avatar` 传入；它们尚未生成资料服务，不能通过持久档案或第二会话绕过缺口。组织/身份代次变化关闭旧弹层；设置页有独立返回入口；账号与组织弹窗普通关闭后返回稳定触发器，scope 失效关闭不抢新页面焦点。

具体品牌、文字、数据契约和可信权限码消费下游唯一 PRD；按[提取与定制合同](../application/extraction.md)替换内容，保留路由、会话及 API owner。代码资产由[应用装配器](../application/files.ts)按已选操作返回，设计与接线清单见[应用接线合同](../application/wiring.md)。只复制页面或函数不算接入完成，须验证入口、主流程、最高风险失败及依赖未选时的缺席。
