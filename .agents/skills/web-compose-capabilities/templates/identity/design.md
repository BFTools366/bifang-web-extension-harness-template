# 基础用户系统固定设计与接线

- 路由/槽位：/login、主界面用户区。
- 固定设计：从已有客户端提取品牌说明与表单分区，窄屏收为单列；表单含带本地化占位提示的账号、密码、提交、错误和 Mock 说明，最下方仅放设置入口。语言/外观集中到无需登录的 `/settings`，即时生效并支持安全返回，离开认证页清空输入。主界面右上固定头像、昵称、展开指示的账号菜单，语言、外观也导航到同一设置页，退出由分隔线和危险色区分。已启用组织与已有真实账号设置由组合层注入。
- 代码接线：登录、恢复、退出使用一个 identitySession；私有路由 beforeLoad 先校验，匿名跳登录并只保留已声明的安全返回目标；HTTP owner 自动携带已接受 Token，当前 401 与退出清理会话。
- 操作边界：不附带注册、找回、组织或权限。

`IdentityMenu` 只拥有身份触发器、退出及菜单关闭，`AccountMenu` 组合偏好与可选 `organization` / `settings` 菜单节点，头像以可选 `avatar` 传入；不新增资料服务、持久档案或第二会话。组织/身份代次变化关闭旧弹层；偏好关闭后返回稳定账号按钮。主壳及交互顺序以 [主界面设计](../application/design.md) 为准。

具体品牌、文字、数据契约和可信权限码消费下游唯一 PRD；按[提取与定制合同](../application/extraction.md)替换内容，保留路由、会话及 API owner。代码资产由[应用装配器](../application/files.ts)按已选操作返回，设计与接线清单见[应用接线合同](../application/wiring.md)。只复制页面或函数不算接入完成，须验证入口、主流程、最高风险失败及依赖未选时的缺席。
