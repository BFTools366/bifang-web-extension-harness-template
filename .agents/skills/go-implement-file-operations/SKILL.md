# Web Harness：实施 Go 文件操作

读取当前实际允许根和用户操作；使用 filepath.Abs/Rel、Lstat 与真实路径检查限制越界和符号链接。服务接收文件标识而非任意宿主绝对路径；校验大小、类型与内容，流式处理，临时文件归当前请求并清理。覆盖同名冲突、取消、磁盘失败和越界，写成功后刷新只重读；返回真实可读结果。产品数据不写源码或模板资产目录。标准库足够时不加依赖，返回调用方。
