# 中性大后台页面设计

复用当前 Mantine theme、系统字体、单一品牌强调色与既有 SaaS 大后台 shell。只为已选管理功能添加导航，不制造无数据的运营仪表盘、指标或支付品牌墙。本文件是页面规格，具体下游仍按 PRD 展示并选定原型。

## 基础应用布局

复用 `docs/MANTINE_UI_GUIDELINES.md` 的 SaaS 基础设计：匿名默认登录，桌面品牌与表单分区，语言/外观收在表单内；无公开注册或会话组织切换。登录后采用完整高度侧栏、顶部工具区、右上账号菜单和宽幅内容，侧栏底部显示当前操作员与服务返回的后台上下文。导航可收起，窄屏改为等价抽屉，退出与账号设置始终可达。

管理目标组织只作为业务查询/操作对象，在页面标题、筛选和确认中标明，不放进账号菜单冒充操作者组织切换。真实数据缺失使用空态与恢复入口，不以假收入、假订单、假配额补齐仪表盘。Mock 认证使用可展开说明，不提供默认跳过登录按钮。

## 导航与页面结构

- 商品管理组：商品分类、商品管理。
- 客户与组织组：组织管理、用户与成员；成员功能可位于组织详情内，不重复维护两套状态。
- 交易查询组：订单管理、钱包与支付记录。
- 平台管理组：平台访问控制、操作审计。

每个入口和操作独立受权限及服务能力控制；无权限导航不出现，直达仍有守卫。顶部显示当前操作员，目标组织只在列表筛选、详情标题和操作确认中显示；不得放成登录头像的组织切换器。

## 核心页面

| 页面 | 主体布局                                    | 详情与编辑                                                                                        |
| ---- | ------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 分类 | 左分类树，右当前节点资料与直属商品/子类信息 | 轻量新建/编辑 Modal；移动父级单独确认，列出影响，不默认拖拽或级联                                 |
| 商品 | 分类筛选、关键词/状态与真实分页表格         | 独立详情/编辑页，资料、分类、服务支持的规格价格、发布状态分区；历史订单链接按权限显示             |
| 组织 | 名称/标识/状态筛选与列表                    | 标题固定目标组织；概览、成员、订单、钱包按服务和权限显示；成员关系与全局账户状态分别标注          |
| 订单 | 订单号、组织/用户、时间和状态筛选与表格     | 独立详情含订单快照、支付尝试、权益（如有）、关联流水和审计；唯一恢复动作为服务允许的状态查询/取消 |

分类深层采用可访问折叠导航，展示选中路径，展开与选择分离；不套用未实现键盘模型的 ARIA tree。商品编辑币种/金额/规格有明确标签与准确单位；发布、下架、归档分别表达，不用一个含糊“保存”隐藏生效影响。

订单支付状态、权益状态与取消/过期信息分开，支付尝试按时间展示服务端结果。取消确认显示订单、目标组织、当前状态和影响，必要原因字段按服务要求提供；不出现“手动已支付”按钮。商品/组织详情跳相关列表时传真实筛选并沿用统一列表状态合同。

## 配套页面

用户详情分开“账户”和“组织成员关系”，每条成员关系标注组织与角色；邀请明确为待接受。负责人交接展示当前/新负责人及影响。平台角色页面只显示可授予范围，客户成员角色不冒充平台角色。

钱包页先展示用户/组织归属、资产/币种、服务端余额/状态，再列流水与支付尝试，关联原订单。默认操作只有查询与刷新，无余额编辑、充值或提现。审计页显示操作员、时间、对象、动作、结果与原因，内容按服务脱敏；没有日志清空或默认批量导出入口。

## 交互一致性

列表采用既有 `$web-implement-list-view` 的 Router/Query 分工，保留查询、分页及返回位置。批量操作只在真实需要且服务提供逐项状态/原子边界时增加，不因后台惯例默认选择框。加载、空态、无权限、错误、冲突、结果未知、成功但刷新待更新分别呈现。

新建、发布、停用、迁移、移除成员、交接负责人和取消订单的反馈说明具体对象及结果；按实际影响提供确认与服务要求的原因，不为普通只读查询重复确认。失败保留输入；版本冲突展示变化并允许核对，不能把用户草稿直接覆盖服务新值。

每页一个可见 h1，控件具备名称和选中状态，错误关联输入，弹窗有焦点与返回路径。窄屏筛选换行、表格有可识别的横向滚动或合适移动形态；亮暗、320 CSS px、200% 文字、中文/英文、键盘及状态播报按 UI 规范验证。金额带币种，时间采用明确 locale/时区，不用颜色单独表达状态。
