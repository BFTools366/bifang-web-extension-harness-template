# Web Harness 下游初始化表单

创建 React Web 或 Plasmo Chrome MV3 / Firefox MV2 Extension 下游使用固定表单逐项引导基础输入并生成项目标识；Extension 另需非空简短说明。复用当前请求或命令已提供的合法值，只问缺失或非法项；Web 说明和确认来源不作为用户必填字段，API 地址可后续配置。

## 固定问题清单

[`initialization-questions.json`](initialization-questions.json) 是 Agent 与 CLI 共用的题目文案唯一事实来源。创建前读取该文件，按 `basic` 的键顺序处理基础字段，再按 `policy` 的键顺序处理适用的自定义策略，最后使用 `confirmation`；字段是否需要询问仍由下文的条件与校验决定。

- `title` 是固定问题名称，`question` 是固定题面；逐字使用，不自行缩写、改写、合并或新增问题。首次询问、非法回答重问、默认值变化与中断恢复都保持同一名称和题面。
- 每个选项固定显示为 `label（description）`，使用中文全角括号，说明紧跟选项名称。说明必须表达选择的实际意义，不能只展示 `web`、`enabled` 等技术值；保留清单的选项顺序，不因推荐值变化重排。
- `hint` 提供输入格式与适用说明；建议/默认值、错误原因和已答进度另行展示，不能拼入或替换题名、题面及选项说明。选择题只展示当前题目的选项，自由文本题不虚构选项。
- Agent 每轮只发一题并等待实际回答；不得把整份表、多个问题或五项策略合成一轮问卷。Agent 复用用户主动提供的多个合法值，只继续询问下一项缺失或非法值。CLI 基础问答的 JSON 仅接受基础与可选输入字段；自定义策略经命令行参数或逐项回答提供，JSON 中的不支持字段会明确报错。
- 使用问答工具时，完整保留问题名称、题面和各选项的括号说明；工具的短标题、推荐标记或预选值不能替代这些内容。聊天中的建议值需明确回答接受；仅 CLI 在题面之外明确提示“回车采用”的配置项允许实际空回答接受。

## 交互状态机

- 字段状态只取 `待首轮询问`、`待条件询问`、`待校验`、`已解析` 或 `不适用`。
- 每轮只问一个尚缺失或非法的字段，收到实际回答并校验后才进入下一项：先项目类型、可选详细需求、显示名称、条件英文译名、父目录绝对路径、条件说明及 Agent 策略。CLI 直接接收普通文本，仍兼容用户主动附带多个字段的 JSON 对象；不要求一次填表。项目类型显示 1.Web / 2.Extension，可直接输入 `1` / `2`，不设默认值。策略使用中文“预设/自定义”，建议值另行展示；CLI 实际回车可接受已提示的建议值；已有单项覆盖时建议自定义。项目标识由项目名称的英文翻译自动生成小写 ASCII kebab-case；Agent 负责翻译并传入 `englishName` / `--english-name`，英文名称可直接生成，不要求用户填写 id，不转拼音、不从父目录名推导。纯终端无翻译能力时只补问英文译名。已有显式合法 id 优先复用。
- 非交互 CLI 的第一个位置参数必须是用户原始输入的完整绝对父目录；交互终端省略位置参数时，轮到父目录字段再单独补问 `targetRoot`，最终目录自动拼接为“父目录/id”，没有可靠默认父路径。相对路径在任何写入前拒绝，不静默补成绝对路径。
- Web 说明默认使用显示名称；Extension 缺失说明时单独补问，空白值必须修正；三份 API 地址缺省为空字符串，表示未配置，不猜测 endpoint。开发地址可主动提供或后续配置，测试和正式地址不在首轮询问；正式发布前必须补齐 HTTPS 正式地址。
- 用户主动提供的可选字段全部复用并校验，包括主动提供的 JSON 中附带的地址。非法已填值进入后续修正轮；已经合法的字段不重问。
- 确认来源自动记录为“当前用户”，已有明确合法来源时复用；不单独询问姓名或确认来源。时间记录最终收齐日期。
- 选择“自定义”后每轮只询问一个缺失或非法的策略字段，展示同名预设值作为建议默认值；题面明确“回车采用”，接受后记录来源。已主动提供的合法策略值全部复用。选择“预设”后直接展开确定性选择。
- 完成解析后展示唯一完整汇总，包含源/目标原始路径与规范路径、身份、已配或未配的地址、品牌、完整 policy 和输入来源；只询问一次“按此创建？”。
- 完整汇总确认前只允许读取规则、解析输入和规范路径，以及在源/目标之外的临时目录提取完整需求文本、按品牌 Skill 生成或导入 Logo 候选，不创建目标/staging、复制、安装、初始化 Git 或修改源文件；拒绝确认不写入源/目标/staging。非交互命令通过完整必需参数表达创建意图。
- 可选创建需求按 [输入与交接合同](requirements-intake.md) 委托需求定义进行只读分析并交接；不在模板源写产品记录或业务代码。endpoint、凭据、正式业务确认、发布需求与 E2E 选择仍在成功下游按各自门禁处理。
- 项目内 `design-taste-frontend` 默认安装，已有有效版本原样保留，不作为表单或策略选择，不全局安装。

## 基础输入与自动字段

| 顺序 | JSON 字段 / 命令行参数         | 字段                  | 规则                                                                        |
| ---- | ------------------------------ | --------------------- | --------------------------------------------------------------------------- |
| 1    | `projectType` / `--type`       | 项目类型              | 1.Web（`web`）或 2.Extension（`extension`），可选编号，无默认值。           |
| 2    | `name` / `--name`              | 项目显示名称          | 非空文本。                                                                  |
| 自动 | `id` / `--id`                  | 项目标识              | 由英文译名生成，匹配 `^[a-z][a-z0-9]*(?:-[a-z0-9]+)*$`；显式值优先复用。    |
| 3    | `targetRoot` / 位置参数        | 源 Harness 外的父目录 | 模板之外；最终目录为此路径/`id`，该子目录须不存在或为空。                   |
| 4    | `policyMode` / `--policy-mode` | Agent 策略模式        | 预设（推荐）或自定义；也接受 `recommended` / `custom`，预设不接受单项覆盖。 |

## 可选输入与后续配置

- `requirementsFile` / `--requirements-file`：详细需求文档绝对路径，CLI 接受非空 UTF-8 `.md` / `.txt`，最多 1 MiB；可选题实际回车表示不提供。Agent 可复用已给附件或全文，由需求定义分析界面需求、由功能组合选择独立能力，再将完整原文放在源与目标之外临时目录传入；创建确认只授权原文随 staging 保存到新项目 `docs/requirements/source.txt`，不把建议视为已批准 PRD。没有文档继续现有逐项选择。

- `englishName` / `--english-name`：项目名称的英文翻译，用于自动生成标识；英文显示名称可省略，不写入下游身份配置或自动扩充本地化。中文名称由 Agent 翻译，纯终端缺失时补问；非交互缺失且未给显式 id 时在写入前拒绝。
- `developmentBaseUrl` / `--development-base-url`：开发 API 地址，可留空或后续配置。
- `testBaseUrl` / `--test-base-url`：测试 API 地址，初始化无需提供，可后续配置。
- `releaseBaseUrl` / `--release-base-url`：正式 API 地址，初始化无需提供，正式发布前必须补齐 HTTPS 地址。
- 已填地址必须是无凭据、查询参数、片段 的绝对 HTTP(S) URL；正式地址始终只接受 HTTPS。三份环境文件仍生成；普通文件校验允许空地址，活动 Release 校验要求正式地址非空。
- `description` / `--description`：Extension 必填，非空且最多 132 字符，已提供则复用；Web 缺省或空白时使用显示名称。扩展所有语言的名称最多 75 字符。
- `identityI18n` / `--identity-i18n`：可选 JSON 字符串，包含 `defaultLocale: en|zh_CN` 与 `translations` 对象；每份翻译必须同时包含非空 `name` 和 `description`。默认语言使用根字段，不重复记录在 translations。缺失翻译回退默认身份，未知语言/字段或不完整翻译在写入前拒绝。
- `confirmedBy` / `--confirmed-by`：仅复用已明确来源，缺省或空白时自动记为“当前用户”，不主动询问。
- `brandColor` / `--brand-color`：合法十六进制颜色，缺省 `#4C6EF5`。
- `--logo`：可选本地图像，由 Logo 预检验证；缺省确定性生成。Agent 路径先按 `$web-prepare-brand-identity` 生成/导入并预览，候选临时目录位于源和目标之外；汇总列出母版及当前宿主派生文件。

## 条件策略字段

“自定义”模式按下列顺序逐项询问，结果物化为 `enabled` 或 `disabled`；交互回答另接受“启用/关闭”“是/否”，回车采用本项展示的预设建议值：

1. `user_owned_tasks`
2. `superpowers`
3. `parallel_worktree_subagents`
4. `acceptance_smoke`
5. `e2e_hint`

`user_owned_tasks` 推荐/default 都为 `disabled`。`e2e_hint` 仅建议本次发布首次 E2E 选择，同一发布复用已明确的选择。“预设”确定性物化为：

```yaml
user_owned_tasks: disabled
superpowers: disabled
parallel_worktree_subagents: disabled
acceptance_smoke: enabled
e2e_hint: disabled
```

## 路径与来源汇总

最终汇总逐字展示源 Harness 根的脚本输入与 `realpath` 规范值、用户提供的原始绝对父路径、拼接项目标识后的完整项目路径与解析既存祖先后的规范值。来源标记固定入口、命令行位置参数、交互问答、主动 JSON 表单、交互接受默认值、英文名称自动生成、显示名称默认值、未配置地址、自动确认来源、品牌默认值或确定性预设。没有实际配置的地址明确显示“未配置”，正式地址提示发布前必须补齐。

路径汇总只是写入前确认事实，initializer 仍独立执行空目录、符号链接、源外位置、目录名和 source freeze 门禁。目标不存在时只读解析最近已存在祖先，不为规范路径提前创建目录。

## 原子写入边界

- 最终确认后、首个目标或 staging 写入前，冻结纳入复制的源文件路径、完整字节与权限模式，以及 `Version.md`（存在时）和可用 Git HEAD/完整 porcelain 状态。
- staging 初始化完成、原子发布前复核同一事实；纳入文件的新增、删除、字节或模式变化，Version、Git HEAD 或状态变化都失败关闭。
- 首次父目录写入前使用规范目标路径；创建唯一 `.<id>.harness-init.lock` 租约，冻结父目录、staging、holding 与既存空目标的设备/inode/模式。身份漂移停止发布；holding 回收失败只报告已发布但有残留，不改写成功结果或沿替代树清理。
- Node 标准库不提供跨平台目录 `rename-if-absent`，同机进程故意绕过租约的竞态不属于内核级保证；检测到目标竞争仍须失败关闭。

创建只确认宿主、固定工程输入及可选原文交接；业务模块在成功下游的唯一 PRD 中按操作选择，初始化不注入认证、组织、权限、商品或交易页面。
