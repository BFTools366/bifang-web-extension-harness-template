# Web Harness：验证 Go 服务行为

读取根 Workspace、当前操作契约及已有测试，仅测试受影响业务。测试在服务成员 cwd 执行，默认使用 Go testing、httptest 与临时 SQLite；成功、最高风险失败、越权和重启持久化按本次变化覆盖。

业务联调必须启动真实服务，通过实际 HTTP 验证 handler/SDL 和前端 typed adapter；健康接口只证明中性服务，不能代替用户、订单或钱包闭环。测试账号只创建在隔离数据库，不进入产品 fixtures 或仓库；服务端口、数据库与进程由当前测试精确拥有并回收。

运行相关 go test；身份/并发/事务变化按需要加 race 或多请求测试。记录实际接口、状态、持久化和失败恢复证据，未执行项明确报告。候选、浏览器和发布仅由相应独立事件触发，完成后返回调用方。
