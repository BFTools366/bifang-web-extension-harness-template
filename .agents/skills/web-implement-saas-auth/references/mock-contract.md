# SaaS 认证 Mock：协议与状态回归

仅在已初始化 Web 的当前认证范围使用 Mock 时读取。数据层共同规则见 [未配置远端地址时的能力分工](../../../../docs/DATA_ACCESS.md#未配置远端地址时的能力分工)，认证不变量见 [会话合同](session-contract.md)。本文件提供条件性回归方法。SaaS 客户端创建复用固定演示账户和权限 fixture（由生成代码和下游 README 明确记录），不收集真实账号密码、不猜 endpoint 或实现完整模拟服务器。

## 协议入口与证据

- 已采用可信协议且依赖其报文语义时，从实际公开 API 入口经过请求序列化、内存 exchange、响应校验和领域投影；多个入口复用对应边界解析器。只调用底层内存函数或测试中另造一套协议不能证明产品入口正确。
- 在内存 exchange 边界核对方法、路径、Header 与 body 的方向；公开登录/注册/验证码/找回不带旧会话凭据。仅在合同采用时核对 Bearer、TokenPair、追踪 ID、成功/空结果和错误封装，不强加某服务协议。
- 观察器只用于隔离测试，不把完整报文写到产品日志。断言 Mock 全程零 Fetch/真实 HTTP client 调用；演示值与持久化边界遵循数据规范，不能把 Mock 请求记录称为实测网络。
- 同时存在 REST 与 GraphQL 时分别校验原始封装、字段命名、可空性及错误形态。来源 SDL 与实际 Mock 执行支持面分别记录；只模拟本次采用的查询，不自行实现完整 GraphQL 语法或静默接受不支持的操作。

## 状态与时间所有者

服务状态拥有账号、成员资格、允许动作、已签发会话与验证码；客户端适配器和认证协调者消费它，不各自维护竞争副本。同一服务的多个客户端或协议入口显式共享状态；独立测试使用新实例，不依赖运行顺序或进程全局残留。

明确刷新页面、重建服务实例和重建客户端分别保留或重置什么。演示引用即使允许持久化，也不证明服务状态跨刷新存活；恢复结果必须符合已声明生命周期，不能凭前端存储重建权限或账户状态。

时效与限流由可注入时钟驱动，异步先后由可控制的完成边界驱动。测试推进时间或释放指定请求，不真实等待验证码到期，不用时间戳比较冒充跨标签页原子性。

## 按当前采用操作选择场景

| 当前范围           | 成功与最高风险失败证据                                                                                          |
| ------------------ | --------------------------------------------------------------------------------------------------------------- |
| 登录、凭据校验     | 服务身份与权限来源一致；缺少/错误类型/过期/吊销等已定义错误分别映射，不把健康检查或任意 2xx 当成校验成功。      |
| 多客户端退出或改密 | 两个客户端连接同一服务态，按真实合同证明会话级或账号级吊销；不能仅删除一个本地引用后断言全部会话失效。          |
| 未公布签发         | 存储失败、结果迟到时仅丢弃该次结果；全账号退出与临时清理分开，后来登录保留其自己的会话所有权。                  |
| 客户端验证码注册   | 目标/用途隔离、成功一次性消费、错误/到期/重发与尝试窗口；固定数值是显式 fixture，不能反写为未确认的服务默认值。 |
| 两模式密码找回     | 按服务合同吊销；本地只清匹配账号与当前代次，删除失败阻断，晚于新登录的结果无本地清理及导航权。                  |
| 组织或权限变化     | 共享服务态的当前组织与权限为权威；冷恢复不能用存储中的旧组织覆盖服务已接受的新 scope。                          |
| 显式凭据刷新       | 仅本次已采用时覆盖访问/刷新凭据的类型、期限与轮换；不从 Mock 支持刷新推导 401 自动 refresh/replay。             |

未采用的操作标明不适用，不为补齐表格生成功能。上述测试只证明下游边界与 Mock 的可观察语义；真实 HTTP 接入仍须重新验证协议、服务端授权和吊销范围，最终浏览器与候选验证按独立事件执行。
